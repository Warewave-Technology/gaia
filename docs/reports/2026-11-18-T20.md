## ADR'lerden sapmalar / öneriler

1. **ONAY GEREKİYOR (ADR-007 §7): arayüz yığını.**
   - **ADR'nin dediği:** "Go `html/template` + vendored htmx, no CDN, no Node toolchain; works without JavaScript for reading."
   - **Yapılan (PO kararı 2026-11-17):** heimdall yığını (React/TypeScript/Vite).
   - **Neler aynı kaldı:**
     - CDN yok;
     - `web/dist` commit'li ve binary'ye gömülü; `go build`, `make dist` ve kurulum Node istemiyor;
     - Node yalnız arayüzü geliştiren için gerekli;
     - CI dist'in kaynakla aynı olduğunu denetliyor.
   - **Neler değişti:** okumak için JavaScript gerekiyor. JS olmadan `<noscript>` notu `gaia status`'u ve export'u gösteriyor; okuma CLI ve API ile tam olarak mümkün.
   - **Öneri:** §7'yi "React/TS, dist commit'li ve gömülü, Node yalnız geliştirmede" diye güncellemek.
2. **ONAY GEREKİYOR (ADR-007 §6, kimlik doğrulama): tarayıcı oturumu.**
   - Tarayıcıda token sayfaya verilmiyor; `__Host-gaia_session` cookie'si kullanılıyor (HttpOnly, Secure, SameSite=Strict, Path=/). Ömrü CLI token'ıyla aynı: 12 saat, aynı lockout.
   - CSRF'e karşı Go 1.25'in `CrossOriginProtection`'ı bütün rotaların önünde. CSP `default-src 'self'`.
   - Bearer token yolu değişmedi.
3. **ONAY GEREKİYOR (ADR-006, ADR-007 §7): export'taki trust anchor.**
   - `anchor.pub` ledger'ın genesis kaydından alınıyor, yani doğrulanan verinin içinden.
   - README ilk adım olarak key_id'yi kurulumda kaydedilen ya da maille gelen günlük rapordaki değerle karşılaştırmayı söylüyor (spec §3).
   - Export'taki günlük rapor, maille gelen rapordan zayıf bir çapa. README bunu söylüyor ve mailden geleni de `-head` ile vermeyi öneriyor.
   - `restore-tests.json` kolaylık için bir özet; imzalı değil, kanıt sayılmaz. Kanıt bundle'lar ve ledger.
   - **Soru:** export'un kendisi de imzalanmalı mı? Bundle'lar ve ledger zaten imzalı.
4. **ONAY GEREKİYOR (ADR-007 B4.3, T19'dan devam).**
