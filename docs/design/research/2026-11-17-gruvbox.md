## What makes gruvbox look refined, and pitfalls

- Zed's Gruvbox theme (the best reference for application chrome): status text in the full accent; each status also a
  dark, low-saturation tinted background and a slightly lighter tinted border (dark: error #590a0f / #771617, warning
  #572e10 / #754916, success #322b11 / #4a4516; light: pale tints, e.g. error #f4d1c9 / #e8ac9e). Body fg0, muted
  #c5b597 (dark) / #5f5650 (light), focus and accent blue.
- Refined, not "retro terminal": a proportional UI face (monospace only for IDs and hashes); elevation by bg0_h/bg0/bg1
  layers rather than heavy borders; accents only where they carry meaning, never on large areas; softer fg for long text.
- Pitfalls: muddy neutral accents; red, orange and yellow blur (faded red and faded orange are almost the same in light
  mode); red/green confusion under deuteranopia; light-mode yellow and green fail AA; too many saturated hues at once.

## Fonts (SIL OFL 1.1; ship OFL.txt; latin + latin-ext subsets)

| Option | Weights | woff2, 400 (latin + latin-ext) | Notes |
|---|---|---|---|
| IBM Plex Sans + IBM Plex Mono (recommended) | 100–700, italics | Sans 22.6 + 16.0 KB; Mono 14.7 + 13.3 KB | Engineered, warm, typewriter roots in the Mono; reads as serious infrastructure. Reserved Font Name "Plex": ship upstream files unchanged. |
| Recursive | 300–1000; MONO, CASL, wght, slnt, CRSV axes | 23.5 + 20.1 KB | Sign-painting roots, closest to gruvbox's "retro groove"; one family for UI and hashes (CASL=0). |
| Inter + JetBrains Mono | 100–900 / 100–800 | Inter 23.7 + 35.0 KB; JBM 21.2 + 7.3 KB | Most legible, but makes gruvbox look generic. |

## Recommendations

1. OK green ✓, WARNING yellow !, CRITICAL red ✕, UNKNOWN purple with a dashed/hatched chip ?. Never gray for UNKNOWN
   (gray reads as quiet/fine). Keep orange out of status.
2. Status chips Zed-style: tinted background and border, accent for glyph and edge, label in fg0/fg1.
3. Dark: page bg0_h #1d2021 (bright red reaches AA there); cards bg0 / bg1.
4. Light: page bg0 #fbf1c7, cards bg0_h #f9f5d7; bg1 only for headers; never accent text on bg1.
5. Text: body fg1, headings fg0, secondary fg3 (light) / fg4 (dark); gray only for large or disabled text.
6. Borders: dividers bg1/bg2; control borders bg4 / #7c6f64; focus 2 px blue, 2 px offset.
7. At most four semantic hues (green, yellow, red, purple) plus blue for links and focus.
8. Ship IBM Plex Sans + Mono, latin + latin-ext, 400/500/600 + Mono 400 (~160 KB woff2) with OFL.txt.
