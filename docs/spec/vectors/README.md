# Conformance vectors — Restore Evidence Format v1

CC0 1.0 Universal, like the specification ([`../evidence-v1.md`](../evidence-v1.md), §10).

One directory per vector: `expected.json` (mode, verdict, the set of finding codes), `anchor.pub` (base64 of the
trust anchor's 32 bytes; absent means none is given), and either `bundle/` or `ledger.jsonl` with `bundles/`
(and, for the `head-*` vectors, `heads/`: head statements given to the verifier in file-name order, §6.8).
An implementation conforms when every vector gives exactly its declared verdict and codes.

The vectors are generated by Gaia's `internal/evidence/vectors_test.go` (`go test ./internal/evidence -run
TestVectors -update`) with test keys from fixed seeds; `scripts/check-evidence.sh` runs `gaia evidence verify` on
every one of them in CI. `bundles/.keep` files only keep empty directories in version control.
